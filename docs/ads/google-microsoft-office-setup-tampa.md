## Why there's no repair in here

Google and Microsoft restrict ads for computer and phone repair and tech support (Google can require third-party tech support verification). These campaigns sell **setup and installation** only: office setup, cable management, workstations, printers and networks, business email and TV menu screens. Repair goes on Meta (see `docs/ads/meta-tech-repair-tampa.md`).

So in these ads:
- **Never use:** repair, fix, broken, virus, malware, tech support, technician, help desk, troubleshoot, remote access, pop-up, hotline, or brand names in ad text (Microsoft, Windows, Apple, Google, HP, Dell, Samsung).
- **Don't put the repair prices here.** Speed-up from $75, remote from $69, virus removal $79, PC repair from $79, SSD from $99, iPhone screen from $79 and the $39 diagnosis are Meta-only. If a setup customer asks about a slow computer in person, quote those prices then.
- **Do say:** setup, install, organize, in person, we come to you, quote before we start, call or text.
- If you set a starting price for office setup (for example "Office setup from $___"), add it as a headline and a price asset. Until then, sell "Quote before we start."

## 6. Build it in Google Ads (browser)

1. **Conversions first.** Goals → Conversions → Summary. Confirm `book_call`, `generate_lead` and `click_to_call` exist and show "Recording conversions." If not, create them from GA4 (New conversion action → Import → Google Analytics 4 → Web) or as website events.
2. **Negative list.** Tools → Shared library → Exclusion lists → **+** → name `Office Setup Negatives` → paste the whole negative list from section 2 → Save.
3. **New campaign.** Campaigns → **+** New campaign → Objective **Leads** → conversion goals: keep Book appointment, Submit lead form, Phone call lead → type **Search**.
4. Ways to reach your goal: tick **Website visits** (`https://www.ceoturbo.com/office-setup-tampa`) and **Phone calls** ((678) 558-4327). Name it `Office Setup Tampa | Search`.
5. **Bidding:** Clicks → set max CPC limit $4. (Switch to Conversions after 15+ conversions.)
6. **Campaign settings:**
   - Networks: untick **Display Network**. Untick Search partners for the first month.
   - Locations: Enter another location → Advanced search → Radius → Tampa, FL, **40 mi** → Add.
   - Location options: **Presence: people in or regularly in your included locations.**
   - Languages: English.
   - AI Max / broad match: off. Final URL expansion / automatically created assets: **off**.
   - Ad schedule: Mon–Sat 7:00 AM – 8:00 PM.
7. **Keywords and ads (first ad group).** Ad group name `Office Setup`, paste the keywords from section 2 (keep quotes and brackets). Final URL `https://www.ceoturbo.com/office-setup-tampa`. Display path: `office-setup` / `tampa`. Paste 15 headlines (8 shared + 7 group) and 4 descriptions (2 shared + 2 group).
8. **Assets on this screen:** add sitelinks, callouts, structured snippet and call asset from section 4. Skip image assets for now.
9. **Budget:** $20/day. Review → Publish.
10. **Add the other 5 ad groups.** Open the campaign → Ad groups → **+** → for each: name, keywords, then New ad → Responsive search ad with that group's headlines and descriptions.
11. **Attach the negative list.** Tools → Shared library → Exclusion lists → `Office Setup Negatives` → Apply to campaigns → pick both campaigns.
12. **Location asset.** Assets → **+** → Location → link the Business Profile → apply at account level.
13. **Check.** Ads & assets → each RSA should show "Eligible." If any says "Limited by policy," open it, read the reason, and replace that line.
14. **After 3–5 days:** Insights & reports → Search terms. Add any repair, support or DIY term to the negative list.

## 7. Build it in Microsoft Advertising (browser)

Easiest path: import from Google, then recheck.

1. **Conversion goals.** Tools → Conversion goals → confirm `book_appointment`, `submit_lead_form` and `contact` show "Recording." If not, create each: **Create** → Website → Event → Action equals the name → Category as in section 5 → Count: Unique → Revenue as listed → Save.
2. **Import.** Import → **Import from Google Ads** → sign in → pick the account → select `Office Setup Tampa | Search` and `Websites Tampa | Search` → Import only new items. Options: import bids and budgets, keywords, ad groups, ads, assets, negative keyword lists; do **not** import Google's conversion goals.
3. **Fix settings after import** (Campaign → Settings):
   - Location: Tampa, FL, 40 mi radius. Location targeting: "People in your targeted locations" (not "or who show interest").
   - Networks: **Microsoft sites and select traffic only** for the first month (turn off "all search and audience partners").
   - Audience network: off.
   - Bidding: Maximize clicks, $4 max CPC. Switch to Maximize conversions after 15+ conversions.
   - Budget: $15/day office setup, $8/day websites (Microsoft traffic is smaller).
   - Automatically generated assets / multimedia ads: off.
4. **Recheck every ad.** Ads & extensions → Ads → open each RSA. Look for anything flagged. Microsoft is stricter on "tech support" wording, and the ads already avoid it, but confirm "Approved."
5. **Negative list.** Shared library → Negative keyword lists → confirm `Office Setup Negatives` imported and is associated with both campaigns. If not, create it and paste section 2.
6. **Assets.** Ads & extensions → Assets: confirm call (with schedule), sitelinks, callouts, structured snippet. Add a **location** asset (import from Google Business Profile or enter it by hand).
7. **UET check.** Tools → UET tag → status "Tag active." Visit `/office-setup-tampa`, tap call, submit the form, book a time; each goal should register within a few hours.
8. **Scheduled import (optional):** Import → Schedule → weekly, so headline changes in Google carry over. Turn it off if you make Microsoft-only edits.
